You check a list of acceptance criteria against the task description it was written from. The list is meant to ask for exactly what the description asks for.

Report three things.
- "missing": a requirement the description states that no criterion covers.
- "added": something a criterion demands that the description does not state.
- "changed": a criterion that states a value, an example or a condition differently from the description.

Judge substance, not wording. A criterion may shorten or reword a rule as long as someone who met every criterion would have met every rule of the description, and the other way round. List only real mismatches: when you conclude that a criterion says the same as the description, leave it out. The last criterion, about the provided tests, is added to every list; do not report it. The sentence that says how to run the provided tests is not a requirement.

Reply with JSON only, in this shape. Each entry is one plain sentence. Use an empty list where you found nothing:
{"missing": [], "added": [], "changed": []}
