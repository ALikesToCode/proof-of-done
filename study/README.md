# Study: when an agent says "done"

A study of which cheap check tells finished work from unfinished work when a coding agent says
"done", and how much finished work that check refuses.

| Path | What it holds |
| --- | --- |
| [PROTOCOL.md](PROTOCOL.md) | The question, the two stages, the main comparison, the predictions and the analysis. Published on 27 Nov 2026, before any run it describes |
| [diagnostic-2026-11-26/](diagnostic-2026-11-26/README.md) | Why the benchmark and the control evaluation of 25 Nov disagreed on how much finished work the reviewer refused. Prior evidence for the design |
| `stage1/` | The pilot: 48 small tasks, each with a finished and an unfinished version, and the code that runs the four cells. Being built; nothing in it has been run |

No result of this study exists yet. The numbers quoted in the protocol come from the two earlier
measurements in [benchmark/](../benchmark/REPORT.md) and [control-eval/](../control-eval/README.md)
and from the diagnostic.
